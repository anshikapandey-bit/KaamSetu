Build a complete, mobile-friendly web application called
KaamSetu for Impact-A-Thon 2026.

PROJECT PURPOSE:
Connect local workers with suitable and fair work opportunities.

DESIGN:
- Professional green and cream theme.
- Clean, modern interface.
- Large buttons and readable text.
- Mobile-first responsive design.
- Simple navigation for users with limited digital literacy.

FEATURES:

1. HOME PAGE
Show the KaamSetu name and tagline:
"Connect Skills. Create Opportunities."

Add buttons for Find Work and Hire Workers.

2. WORKER SECTION
Allow workers to enter:
- Name
- Skills
- Location
- Experience
- Expected daily wage
- Availability

3. JOB LISTINGS
Display sample jobs for carpenters, electricians,
plumbers, painters and other local workers.

Each job should include:
- Job title
- Required skills
- Location
- Payment offered
- Work date
- Employer information

4. SMART JOB MATCHING
Match workers with jobs based on their skills,
location and availability.

Explain why each job matches the worker.

5. TRUST FEATURES
Display employer verification status clearly.
Flag suspicious listings for human review.
Never falsely label an employer as verified.

6. EMPLOYER SECTION
Allow employers to create sample job listings
and view workers whose skills match their needs.

7. APPLICATIONS
Allow workers to express interest in a job
and view their application status.

8. DASHBOARD
Show total sample jobs, worker profiles,
applications and successful connections.

TECHNICAL REQUIREMENTS:
- Build a functional web application, not just a design.
- Use a suitable frontend and backend.
- Persist data using a database if available.
- If authentication or database setup is unavailable,
provide a clearly labelled demo mode.
- Include realistic sample data.
- Validate forms and display useful error messages.
- Make all navigation and main buttons functional.
- Do not invent real job listings or fake verification.
- Test the complete user journey.
- Fix errors before presenting the final result.

Start by building the core application.
Prioritize working features over unnecessary complexity.

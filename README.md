# 🌉 KaamSetu
### Connect Skills. Create Opportunities.

KaamSetu is a mobile-friendly platform designed to connect local workers with fair job opportunities and help employers find skilled workers.

## 🎯 Our Mission
To make local employment more accessible through a simple and transparent platform.

## ✨ Features

- 👷 Worker profiles with skills, experience, and location.
- 🔍 Local job listings for different skilled workers.
- 🤝 Skill-based job matching.
- 🤖 AI Skill Passport for structured worker profiles.
- 🏢 Employer dashboard for posting jobs.
- 📝 Job application tracking.
- 🛡️ Trust indicators for job listings.
- 📱 Mobile-friendly user interface.

## 🛠️ Technology Stack
Built using AI-assisted development with Replit. Refer to the source code for the frameworks and technologies actually implemented.

## 👥 Target Users
- Local workers and tradespeople
- Small businesses and employers
- People seeking local employment opportunities

## 🌍 Expected Impact
KaamSetu aims to improve access to job opportunities and help workers connect with suitable employers.

## 🚀 Project Status
Prototype in development for Impact-A-Thon 2026.

## ⚠️ Demo Notice
Sample data may be used for demonstration. AI features and employer verification should only be considered operational when implemented and tested.
